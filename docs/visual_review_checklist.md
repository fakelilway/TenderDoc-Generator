导出后人工逐项目视核对。**用 Word 或新点软件打开**（商务卷的填空字段是 VML 文本框，Pages 预览可能不显示那层文字，但底图与对齐永远正确）。自动冒烟见 `backend/scripts/visual_regression.py`。

## 商务卷（照抄格式章 + 填空叠层）

- [ ] 每页与招标原件**像素级一致**（整页截图底，无裁切/拉伸/旋转）。
- [ ] 填空下划线上的可编辑框**对齐**，不溢出、不串行。
- [ ] 已知字段**预填正确**：投标人名称、注册地址、法定代表人、联系电话等。
- [ ] 未知字段留空且**可编辑**（点进去能打字）。
- [ ] 签章位（盖单位章）保留、位置正确。
- [ ] 目录页 / 卷内表单顺序与招标格式一致。
- [ ] 页眉页脚、页码与原件一致。
