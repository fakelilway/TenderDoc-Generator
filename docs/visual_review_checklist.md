# 人工终审视觉清单（Phase 3）

导出后人工逐项目视核对。**用 Word 或新点软件打开**（soffice 对"多节 + 浮动文本框"有渲染膨胀缺陷，页数不可信）。自动冒烟见 `backend/scripts/visual_regression.py`。

## 商务卷（照抄格式章 + 真值填充，可编辑）

- [ ] 版式与招标原件**一致**（Word 招标=OOXML 原样；PDF 招标=福昕转可编辑 Word，真段落真表格）。
- [ ] **无文字叠印**：同一位置不出现两层重叠文字（浮框长条款叠印是 2026-08 修掉的根因病，重点看封面与长条款页）。
- [ ] 填空下划线上的值**对齐**、下划线连续无断线，不溢出、不串行。
- [ ] 已知字段**预填正确**：投标人名称、注册地址、法定代表人、联系电话等。
- [ ] 未知字段留空且**可编辑**（点进去能打字）。
- [ ] 签章位（盖单位章）保留、位置正确；招标原件红章已清。
- [ ] 目录页 / 卷内表单顺序与招标格式一致。
- [ ] 页眉页脚为标书自己的页码（"第X页/共Y页"），招标原件页码已清。

## 技术卷（生成正文，独立成文）

- [ ] 目录**只含技术内容**（施工组织设计 + 其他内容），**无**资格响应/投标保证金/项目管理机构等商务串入。
- [ ] 字体字号符合正奇排版（宋体正文、黑体标题、行距）。
- [ ] 施工组织设计**有工程针对性**、篇幅足够、**逐条响应评分点**。
- [ ] 无"待补充/TODO/AI生成"等元话语。
- [ ] 表格、图表位渲染正常，无 Markdown 残留（### / 管道符）。
