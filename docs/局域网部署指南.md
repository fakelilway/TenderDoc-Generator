# TenderDoc 局域网部署指南（公司内网一键版）

> 目标：把系统装在办公室一台 **Windows 主机**上，作为局域网服务器；
> 其他电脑**不用装任何东西**，只用浏览器访问它的局域网地址即可。
> 全部数据（数据库、公司档案、证书图片、生成的标书）都存在这台主机上。

整套系统被"打包"成 5 个部件，一条命令全部起来。你**只需要改两三个配置值**，
剩下的都是自动的。

---

## 一、术语先说人话

| 你会看到的词 | 人话解释 |
|---|---|
| Docker / 容器 | 一个"标准集装箱"。系统的每个部件装进箱子，一条命令全部启动，不用在 Windows 上一个个装环境。 |
| 局域网 IP | 服务器电脑在公司网里的门牌号，形如 `192.168.1.100`。别的电脑靠它找到系统。 |
| 前端 / 3000 端口 | 网页界面。别人访问的就是 `http://门牌号:3000`。 |
| MinIO / 9000 端口 | 文件仓库。下载标书、看证书图片时浏览器要用它。 |

---

## 二、一次性准备（只做一次）

### 1. 在服务器电脑上装 Docker Desktop
- 到 Docker 官网下载 **Docker Desktop for Windows**，按提示安装（需要 Windows 10/11）。
- 安装后启动它，等到左下角图标变绿（表示 Docker 引擎已就绪）。

### 2. 给服务器电脑设一个"固定"局域网 IP（强烈建议）
- 否则电脑重启后门牌号可能变，别人就访问不到了。
- 做法：在公司路由器后台把这台电脑绑定成固定 IP，或在 Windows 网络设置里设静态 IP。
- 不确定当前 IP：在服务器上按 `Win+R` 输入 `cmd` 回车，敲 `ipconfig`，
  看 **IPv4 地址**那一行（通常 `192.168.x.x`）。记下它。

### 3. 放行 Windows 防火墙（让别的电脑能连进来）
在服务器上"高级防火墙设置 → 入站规则 → 新建规则 → 端口 → TCP"，
分别放行 **3000** 和 **9000** 两个端口（允许连接）。
> 不放行的话，服务器自己能打开网页，但别的电脑打不开——这是最常见的"卡住"原因。

---

## 三、把文件放到服务器

1. 把整个项目文件夹拷到服务器电脑（比如放到 `D:\TenderDoc-Generator`）。
2. **把开发机上的 `backend/.env` 一并拷过去**，放到服务器的 `backend/.env`。
   > 这个文件装着你的 AI 密钥、福昕账号等，系统靠它才能写标书、转 PDF。
   > 它默认不进代码仓库，所以要手动拷。

---

## 四、填配置（只改两三个值）

在项目根目录，把 `.env.example` 复制成 `.env`：

```bat
copy .env.example .env
```

用记事本打开 `.env`，改这两处：

- `SERVER_LAN_IP=` 改成第二步记下的服务器 IP，例如 `SERVER_LAN_IP=192.168.1.100`
- `JWT_SECRET=` 里已经预置了一串随机密钥，**保持不动即可**（也可自己换一长串）。

其余保持默认即可。保存关闭。

---

## 五、一键启动

在项目根目录打开命令提示符，运行：

```bat
docker compose up -d --build
```

- **首次启动会比较久**（要下载部件、安装依赖、下载 AI 向量模型约 1.5GB），
  视网速可能 20~60 分钟，属正常，耐心等。**只有第一次这么久**，以后开机秒起。
- 出现类似 `Started` / 全部 `running` 字样即成功。

查看是否都起来了：

```bat
docker compose ps
```

5 个部件（postgres、redis、minio、backend、frontend）都是 `running/healthy` 就对了。

---

## 六、其他电脑访问

在**任意办公电脑**的浏览器里打开：

```
http://<服务器IP>:3000
```

例如 `http://192.168.1.100:3000`。

- 默认管理员账号：**admin**，密码：**tenderdoc**。
- ⚠️ **首次登录后请立刻改密码**，并给同事分配各自账号。

> 服务器本机也可以用 `http://localhost:3000` 打开——但要求"别的电脑能访问"，
> 就必须用上面的 IP 地址方式，`localhost` 只对本机有效。

## 七、日常操作（都在服务器上、项目根目录运行）

| 想干什么 | 命令 |
|---|---|
| 启动 / 开机后拉起 | `docker compose up -d` |
| 停止（不删数据） | `docker compose stop` |
| 重启某个部件 | `docker compose restart backend` |
| 看后端日志（排查生成问题） | `docker compose logs -f backend` |
| 看所有部件状态 | `docker compose ps` |
| 升级代码后重建 | 更新文件后 `docker compose up -d --build` |

> 设了 `restart: unless-stopped`，服务器重启后 Docker 会自动把系统拉起来，一般不用手动开。

---

## 八、数据存在哪 / 会不会丢

所有数据都存在这台服务器的 Docker "数据卷"里，**不随容器重建而丢失**：

- `postgres_data`：数据库（项目、账号、业绩台账等）
- `minio_data`：公司档案、证书图片、生成的标书文件
- `redis_data`、`hf_cache`：缓存与 AI 模型

> 备份建议：定期把这几个卷导出，或直接备份整台服务器。需要的话我可以给你写个一键备份脚本。

## 九、常见问题

**Q：别的电脑打不开 `http://IP:3000`？**
1. 服务器上能打开 `http://localhost:3000` 吗？能 → 是网络/防火墙问题；不能 → 系统没起来，看日志。
2. 检查第二步 IP 是否填对、是否变了；检查第三步防火墙 3000/9000 是否放行。
3. 确认两台电脑在**同一个局域网/同一个路由器**下。

**Q：能打开网页，但下载标书/看证书图片失败？**
→ 多半是 `.env` 里 `SERVER_LAN_IP` 填错，或防火墙 **9000** 没放行。改对后 `docker compose up -d` 重来。

**Q：写标书/转 PDF 报错？**
→ 需要服务器能上外网（调用外部 AI 和福昕云）。确认服务器能上网，且 `backend/.env` 里的密钥有效。

**Q：首次启动卡在下载模型？**
→ 正常，`.env` 里默认用了国内镜像站。若服务器能直连外网也可把 `HF_ENDPOINT` 那行删掉。

## 十、以后想让"外地/家里"也能访问？

本方案只开放局域网，**不涉及公网、域名、备案、云服务器**，安全。
将来要远程访问，再在此基础上加 **VPN** 或 **内网穿透**（推荐 VPN，最稳）——
那是独立一步，不影响现在这套局域网部署。届时告诉我即可。
